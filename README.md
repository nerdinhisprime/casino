# 🎰 Casino

[English](README.en.md)

Полноценное веб-приложение «слот-машина» на **Nuxt 4**, **Vue 3**, **PixiJS** и **PostgreSQL**. Игрок регистрируется, пополняет виртуальный баланс гемов, крутит анимированную слот-машину с тремя барабанами и смотрит историю своих спинов. Весь стек поднимается одной командой через Docker Compose.

> **Дисклеймер:** это пет-проект, сделанный для обучения и портфолио. В нём используется вымышленная игровая валюта («гемы»). Никаких реальных денег, платежей и настоящего азарта.

## ✨ Возможности

- **Анимированная слот-машина** на PixiJS canvas: три барабана, поочерёдная остановка, подсветка выигрыша
- **Игровая логика целиком на сервере**: результат определяется на сервере по взвешенным вероятностям, клиент только анимирует то, что получил
- **Атомарные ставки**: проверка баланса, списание, выплата и запись в лог спинов выполняются в одной SQL-транзакции с блокировкой строки (`SELECT ... FOR UPDATE`), поэтому параллельные запросы не могут потратить баланс дважды
- **Аутентификация**: регистрация и вход по логину и паролю, пароли хешируются через `scrypt` с индивидуальной солью и проверяются через `timingSafeEqual`
- **Баланс в реальном времени**: обновления баланса приходят в браузер через Server-Sent Events
- **История спинов**: постраничная история всех ставок и выплат (`limit` / `offset`)
- **Магазин гемов**: пополнение баланса готовыми наборами (демо, без реальной оплаты)
- **Настройки аккаунта**: смена имени, смена пароля, удаление аккаунта (с подтверждением вводом фразы)
- **Docker**: отдельные таргеты для разработки и продакшена, Postgres автоматически инициализируется из SQL-скриптов

## 🎲 Игровая механика

Каждый спин выбирает категорию награды взвешенным случайным выбором:

| Категория | Шанс | Множитель |
| --- | --- | --- |
| Ширпотреб | 60% | ×0 (барабаны никогда не совпадают) |
| Редкое | 25% | ×1.5 |
| Засекреченное | 10% | ×5 |
| Тайное | 4.5% | ×25 |
| Нож / Джекпот | 0.5% | ×100 |

При выигрыше все три барабана останавливаются на одном символе. При проигрыше сервер генерирует случайную комбинацию, которая гарантированно **не** состоит из трёх одинаковых символов, поэтому картинка всегда совпадает с результатом.

## 🚀 Быстрый старт

### Вариант 1: Docker (рекомендуется)

Нужен Docker с Compose.

```bash
git clone https://github.com/nerdinhisprime/casino.git
cd casino

cp .env.example .env     # при желании поменяйте значения

docker compose up --build
```

Откройте **http://localhost:3000** (или порт из `VITE_APP_PORT`).

Контейнер `postgres` при первом запуске выполняет все скрипты из `./db`, так что таблицы создаются автоматически. Чтобы сбросить базу, удалите volume:

```bash
docker compose down -v
```

### Вариант 2: Локальная разработка

Нужны Node.js 24, pnpm (`corepack enable`) и запущенный PostgreSQL.

```bash
pnpm install

# создайте базу и примените схему
psql -U <user> -d <db> -f db/01-users.sql -f db/02-spins.sql

# в .env укажите DB_HOST=localhost и свои данные для БД
pnpm dev
```

### Продакшен-сборка

```bash
docker build --target runner -t casino .
docker run -p 3000:3000 --env-file .env casino
```

### Переменные окружения

| Переменная | Описание | Пример |
| --- | --- | --- |
| `VITE_APP_PORT` | Порт, на котором доступно приложение | `3000` |
| `DB_USR` | Пользователь Postgres | `Ludoman` |
| `DB_PSWD` | Пароль Postgres | `sixseven` |
| `DB_NAME` | Имя базы данных | `CazikDB` |
| `DB_PORT` | Порт Postgres | `5432` |
| `DB_HOST` | Хост Postgres (`postgres` внутри Compose) | `postgres` |
| `MAX_SPINS` | Максимум накопленных спинов у пользователя (зарезервировано, см. планы) | `8` |
| `RESTORE_TIMING` | Минут на восстановление одного спина (зарезервировано, см. планы) | `16` |

Значения в `.env.example` подходят только для разработки. За пределами localhost используйте свои данные.

```
├── app/                      # Фронтенд (директория app в Nuxt 4)
│   ├── pages/                # index, slots, login, signup, settings/{index,history,store}

│   ├── layouts/              # основной layout
│   ├── utils/                # клиентские хелперы
│   └── assets/               # стили, шрифты, изображения
├── server/                   # Бэкенд (Nitro)
│   ├── api/                  # REST-эндпоинты (файловая маршрутизация)
│   └── utils/                # пул БД, хеширование паролей, проверка авторизации
├── db/                       # SQL-схема, выполняется при первом старте Postgres
│   ├── 01-users.sql
│   └── 02-spins.sql
├── Dockerfile                # многоэтапный: deps → dev / build → runner
├── Dockerfile.db             # Postgres 17 (+ pgcli)
└── docker-compose.yml        # app + postgres
```

## 🔌 API

| Метод | Эндпоинт | Описание |
| --- | --- | --- |
| `POST` | `/api/auth/signup` | Регистрация (логин ≥ 4, пароль ≥ 6 символов) |
| `POST` | `/api/auth/login` | Вход, устанавливает cookie сессии |
| `GET` | `/api/auth/me` | Текущий пользователь (гость, если не авторизован) |
| `POST` | `/api/slots` | Ставка и спин: `{ bet }` → награда, символы, новый баланс |
| `GET` | `/api/users/me/balance` | Текущий баланс |
| `POST` | `/api/users/me/balance/add` | Пополнение готовым набором (демо) |
| `GET` | `/api/users/me/balance/events` | SSE-поток обновлений баланса |
| `GET` | `/api/users/me/history` | История спинов с пагинацией (`limit` ≤ 100, `offset`) |
| `PATCH` | `/api/users/me/username` | Смена имени пользователя |
| `PATCH` | `/api/users/me/password` | Смена пароля |
| `DELETE` | `/api/users/me` | Удаление аккаунта и истории (с подтверждением фразой) |
